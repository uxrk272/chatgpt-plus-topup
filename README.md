不应该需要。靠谱的自助代充要么完全不碰你的凭证，要么只需要 Session Token 这类登录态信息。凡是索要 ChatGPT 密码、邮箱密码、邮箱验证码的，理由再合理也直接换一家。

### 付款成功后账号还是 Free 怎么办？

先别重复下单。退出账号重新登录，或换无痕窗口试试；确认看的邮箱就是下单填的那个。多数情况是页面缓存没刷新，等 5–10 分钟再看。超过 30 分钟还没变化，拿订单号找平台客服处理。

代充大多是单月买断，到期不会自动扣款，想续费就重新下一单。建议到期前三五天续上，避免会员中断。

### 账号还有在期订阅，能直接再充一个月吗？

一般不行。多数平台付款前会核验账号状态，在期订阅会被拦下，等当前订阅到期、账号回到普通状态后再充。iOS 内购虽然支持覆盖充值，但费用更高。
